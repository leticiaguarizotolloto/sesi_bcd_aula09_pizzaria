# SESI BCD – Aula 09 | Pizzaria

## Sobre o projeto

Este projeto foi desenvolvido durante a Aula 09 de Banco de Dados, com o objetivo de praticar comandos SQL utilizando um banco de dados de uma pizzaria.

## Atividades realizadas

Durante a aula, foram desenvolvidas atividades de DDL, DML e criação de Views.

### 1. Views

Criação de visualizações (Views) para consultar e organizar informações do banco de dados, utilizando relacionamentos entre tabelas.

### 2. DML – Manipulação de dados

Foram utilizados os seguintes comandos SQL:

- `INSERT INTO`: inserção de novos clientes, telefones, pizzas e pedidos.
- `UPDATE`: alteração da quantidade de pizzas em um pedido.
- `SELECT`: consulta e verificação dos dados cadastrados.
- `ALTER TABLE`: alteração da estrutura da tabela para adicionar a coluna CEP.

### 3. Operações realizadas

- Cadastro do cliente Gaspar Oliveira, incluindo endereço, CEP e telefone.
- Registro de um pedido com 1 pizza Margherita e 2 Napolitanas.
- Cadastro da nova pizza "A moda do chef", no valor de R$ 41,90.
- Registro de um pedido com 2 pizzas "A moda do chef".
- Atualização do pedido para 3 pizzas "A moda do chef" e inclusão de 1 pizza Margherita.

## Tecnologias utilizadas

- MySQL
- MySQL Workbench
- SQL
- GitHub

## Arquivos do projeto

- `queries.sql`: comandos de manipulação e consulta de dados.
- `views.sql`: comandos de criação das Views.
- Scripts SQL de criação e população do banco de dados.

## Objetivo

Praticar os conceitos de banco de dados relacionais, manipulação de informações, consultas SQL e utilização de Views, aplicando os conhecimentos em um cenário de uma pizzaria.
